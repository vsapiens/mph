# mph

Python algorithm practice and programming fundamentals.

## Features

- Structured class exercises (clase_1 through clase_8) covering Python basics to intermediate topics
- LeetCode problem solutions with multiple approaches and complexity analysis
- Progresses from hello world through conditionals, arrays, loops, functions, modules, and pygame

## Tech Stack

- Python 3.13
- pygame (used in clase_8)

## Getting Started

### Prerequisites

- Python 3.13+

### Installation

```bash
python -m venv .venv
source .venv/Scripts/activate   # Windows (Git Bash)
pip install pygame              # only needed for clase_8
```

### Running

```bash
python workspaces/101/clase_1.py
python workspaces/leetcode/mergeSortedArray.py
```

## Project Structure

```
workspaces/
  101/          # Class exercises (clase_1 through clase_8)
  leetcode/     # LeetCode problem solutions
```
